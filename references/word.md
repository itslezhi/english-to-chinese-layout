# Word 保真处理

## DOCX：修改原包，不重新建文档

- 优先 OOXML 定点替换。`python-docx` 不覆盖所有浮动对象、图表、字段、修订和嵌入对象，复杂原件先检验保存往返是否丢失结构。
- 不给 `paragraph.text` 或 `cell.text` 整体赋值后声称样式保持：这可能删除 runs、链接、字段和内嵌对象。先获取语义上下文，再写回对应格式跨度；不同语言词序不能按英文字符长度机械切割。
- 保留原有段落、文本框、单元格及表达布局分隔的 `w:br` 等换行，不因翻译或合并 runs 而丢失边界。正文自动折行、提取碎片与原版有意分隔结合文件结构和原页视觉区分，不能一律删除或一律锁死；对应译文保留在原布局单元内，并维持原有对齐、缩进、间距及样式关系。
- 保留样式继承、主题、节、页边距、纸张、分栏、分页符、段落控制、编号、表格网格／合并、行高规则、单元格边距、环绕、锚点、图像尺寸和裁切。
- 不擅自增加表格边框、统一颜色、变更标题样式、删除空白段落或应用美化预设。看似多余的对象可能控制原版分页。

## 清点全部文字位置

按原包实际部件处理，不只读取 `word/document.xml`：

- 正文、嵌套表格、页眉页脚、首页和奇偶页变体、脚注、尾注、文本框。
- DrawingML／VML 形状文字、SmartArt、图表标题和系列标签、图题、表题、替代文本和可读批注。
- 内容控件、链接显示文字、书签关联内容、文档属性的面向读者描述。
- 修订中的插入、删除文字及可见状态。保留修订和批注关系，不替用户接受或拒绝修订。记录覆盖的显示状态，避免备用状态静默残留英文。
- 图表嵌入工作簿的文本与图表缓存一致更新；不改数值、公式、系列顺序、样式或关系。不可编辑的嵌入对象逐项披露。

保留包关系、内容类型和对象 ID。未触及媒体应字节不变；修改图内英文的媒体列入允许变化清单。宏文档保持对应格式和宏二进制，不执行宏。

## 字体、公式与字段

- 对需要的字符范围设置东亚字体，保留西文／数字字体、原字号、颜色和强调。检查中文粗体、斜体、上下标和数学字体回退。
- 保留 OMML 公式、变量名、公式编号、自动编号及引用目标。
- 区分字段指令与可读结果，不翻译 `REF`、`PAGEREF`、域代码、书签名和链接目标。
- 目录使用译后标题并保留链接，核对页码和原页锚定。检查重新计算字段是否带回旧英文、改变编号或移动浮动对象。
- 不用锁死全部字段、展平公式或转换成图片掩盖问题。

## 分页与验证

1. 原件与译件使用相同渲染器、字体、页面设置和修订显示状态比较。Word 与 LibreOffice 分页可能不同，记录引擎，不能据不同引擎结果宣称精确等同。
2. 中文更短不代表页数自然相同。保持节和显式分页，检查跨页表格、孤行、续表、脚注及浮动锚点；不在每段后强加分页以凑页数。
3. 原对象内优先调整断行。字号、行距、行高或段距确需改变时只做局部最小改动并记录；不能删除内容或截断单元格。
4. 可靠渲染器导出临时 PDF／PNG，检查所有页。PDF 仅供核验，DOCX 仍是正式交付物。
5. 保存后重新打开，验证无修复提示，关系、媒体、链接、书签、脚注、图表、字段和编辑能力保留。

## DOC 等其他 Word 格式

真正的二进制 `.doc` 需要支持该格式的转换器或 Word 自动化。可经临时 DOCX 编辑，但回存 DOC 后重新打开并逐页验证，检查转换对对象、公式、域、锚点和字体的影响。不将 DOCX 改名 DOC，不交付 DOCX／PDF 冒充同格式成品。

没有回存能力时完成可行翻译准备，说明该格式暂不能交付；仅在用户已授权改变格式时交付替代格式，不把工具默认转换当作授权。
