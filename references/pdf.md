# PDF 保真处理

## 评估与工具选择

- PDF 是固定版式，不等于可无损编辑的原稿。检查文字是独立对象、共享 Form XObject、路径轮廓还是图片，并检查旋转、裁切框、变换矩阵和透明度。
- 可用 PyMuPDF、pypdf、pdfplumber 检查文字、坐标与对象，用 Poppler 或可靠渲染器检查页面；按实际能力选择，不假定提取顺序即阅读顺序。记录工具版本及字体。
- 有可编辑排版源文件且能重现原 PDF 时，可翻译源文件后导出 PDF，仍须与原 PDF 逐页比对；没有源文件不意味着必须转 Word。
- 数字、扫描与混合 PDF 按页选择路径；轮廓文字、复杂蒙版、签名和动态表单单列。编辑通常使数字签名失效，不复制可视签章来暗示签名仍有效。

## 可编辑文字 PDF

1. 获取文字坐标、字体、字号、颜色、旋转、段落顺序和裁切范围，合并跨行断词与跨页段落后翻译。保留连字、上下标及脚注标记语义。
   仅重建同一连续段落中因自动折行或提取造成的碎片。原版独立的行、段落和文本块分别建模；即使提取器把它们并入同一 block，也不能据此合并写回。文本流顺序、提取边界与视觉布局可能不一致，须依据原页的基线、区域、间距、对齐及样式综合确认。检查现成译本时仍以英文原件为版式母版，不能将译本已有的合并或错位当作正确结构。
2. 尽可能编辑原文字对象或精确移除待译文字后原位写入中文。文本框与基线须转换至同一坐标空间。
3. PDF redaction 可能删除与文字框相交的图像、线条或共享对象。先验证库对 graphics／images 的处理参数并局部测试；禁止未经验证的大矩形批量擦除图表。
4. 保留背景、渐变、纹理、线条和透明度。不在非纯色背景铺白块。只盖住英文却留下可复制的旧英文会造成双重搜索层，须移除对应旧文字或准确更新该层。
5. 为中文嵌入合规字体及正确 Unicode 映射，检查字形覆盖、字符宽度、文本框适配和基线。保留数字、西文、数学符号的原字体与颜色，不拉伸字形模拟适配。
6. 保存完整文档结构，验证书签、内外链接、页标签、注释、附件和表单。不通过逐页新建空 PDF 再贴图丢失这些结构。

## 扫描页与图片内英文

1. OCR 只辅助定位识别；译文对照原图复核，尤其是数字、负号、图例颜色和刻度。保留扫描分辨率、色彩及页面范围。
2. 分离文字与数据线、图标、照片，只修复文字像素后原位排入译文；纯色区用匹配底色，复杂背景需要可验证的局部恢复，不能抹去细节。
3. 没有图表源稿时，保留数据图形，只更换文字。检查 OCR 漏掉的倾斜、旋转、微小及低对比文字。不能用生成式重绘替代数据图表。
4. 提供正确中文可搜索层，避免旧 OCR 英文与新中文同时被提取。扫描原件可保留位图性质，不把原有数字／矢量页面一律栅格化。
5. 无法无损替换的文字记录具体页和图，继续完成可行部分并说明差异。可编辑原图可解决特定缺陷，附录翻译不能冒充图内替换。

## 导出后检查

- 页数、页序、MediaBox、CropBox、Rotate 及可见范围一致。
- 未修改的矢量曲线、数据点及图像保持质量；数据、刻度位置与颜色对应不变。
- 中文可见、可搜索、可复制，提取结果与视觉一致；扫描版验证新增中文层。
- 逐单元对照原版的基线、区域、分隔、对齐和样式关系；检查整段译文的归属及单元之间的关系，识别分隔消失、内容错并、文字片段跨到相邻区域等偏差。不能仅因每个字符都在页面范围内就判为合格；坐标用于辅助定位，仍需视觉确认。
- 书签与链接目的地正确；翻译标题不改变目的地。
- 表单逻辑值与外观一致，字段名和脚本标识不当作普通文字翻译；不默默压平。
- 同步原有辅助功能标签、替代文本、语言标记和阅读顺序；无法保留的结构披露。
- 最终保存、压缩或优化后重新打开并逐页渲染，不能以编辑前预览代替。
